# Alfaiz

Scroll ke hisaab se video play hone wali ek simple web page.

## Kaise chalaye

1. `index.html` file ko browser me kholo, ya GitHub Pages par live link se dekho.
2. Niche scroll karo to video aage badhegi.
3. Upar scroll karo to video wapas pichle frame par aayegi.

## Files

- `index.html`: Poori page, jisme YouTube video aur scroll ka code hai.
- `README.md`: Ye file, project ki jaankari ke liye.
